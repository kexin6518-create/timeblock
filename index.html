使用说明

1. 访问 supabase.com 注册免费账号并创建新项目。

2. 在项目 Settings - API 页面找到 Project URL 和 anon public key。

3. 将 URL 和 key 填入上方配置区并点击保存配置。

4. 在 Supabase 的 SQL Editor 中执行以下语句创建数据表：

create table user_data (user_id uuid primary key references auth.users on delete cascade, data jsonb, updated_at timestamptz default now());

5. 注册并登录后，数据将自动同步到云端。修改数据后 5 秒自动推送。

6. 在其他设备上配置相同的 Supabase 项目并登录即可同步数据。
